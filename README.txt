WEB ULANG TAHUN PUSPA ❤️

Isi:
- index.html = halaman utama
- music.mp3 = tempat lagu ulang tahun
- beberapa foto yang sudah disiapkan

CARA MEMAKAI:
1. Masukkan lagu MP3 pilihanmu ke folder ini dan beri nama: music.mp3
2. Upload seluruh isi folder ke hosting static seperti GitHub Pages, Netlify, atau Vercel.
3. Buka URL hasil hosting.
4. QR code di halaman akan otomatis membuat QR berdasarkan URL tersebut.
5. Kirim URL atau QR code kepada Puspa.

Catatan:
- Website dibuat mobile-first.
- Foto lokal sudah tertanam sebagai file terpisah agar kualitas tetap baik.
- Browser biasanya tidak mengizinkan musik otomatis menyala tanpa interaksi pengguna, jadi tombol Play tersedia.
